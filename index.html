04 FAQ

Questions

What is the difference between menu.html and menu.lua?

menu.html is the menu UI rendered as a web page — the same interface you see in game. menu.lua is the full script you execute; it already contains the UI, so it is the only file you need.

Why is the menu background transparent?

The menu is built as an in-game overlay, so its page has no background of its own. The live preview on this site places it on a dark backdrop.

How do I control the live preview?

Click Click to control on the preview, then use the arrow keys, Q/E, Enter and Backspace just like in game. Press Esc to release the keyboard. Game actions do nothing in the browser — the preview is only the UI.

Where do new menus appear?

Every menu lives in its own folder, e.g. /Zany/ — as soon as a folder is added and listed, it shows up here with its own preview and raw link.
